# Changelog

This changelog tracks the independent development of `ocodo/mdserve`, a hard fork of jfernandez/mdserve.

Upstream release history is retained for context. Changes made after the fork are recorded separately.

## ocodo fork

### Added

- KaTeX math rendering for inline and display mathematics.
- Ocodo Mono font integration and improved code typography.
- Element selection and processing improvements in the preview template.

### Changed

- Updated CSS ordering and typography.
- Adapted the presentation to the ocodo project's preferences.

### Removed

- `CLAUDE.md` and `CONTRIBUTING.md` project-specific instructions and conventions.
